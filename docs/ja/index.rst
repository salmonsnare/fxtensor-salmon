FXTensor
========

FXTensor は、有限マルコフ核を扱う Python ライブラリです。NumPy テンソルに
domain と codomain を与え、必要なら文字列ラベルを付けます。合成、テンソル積、
複製、破棄、条件付け、ベイズ反転は、いずれも
:class:`fxtensor_salmon.FXTensor` のメソッドです。

これはリリース |release| の日本語版です。各ページ上部のバーとサイドバーから
`English <../en/index.html>`_ に移れます。
