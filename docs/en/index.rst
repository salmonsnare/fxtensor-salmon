FXTensor
========

FXTensor is a Python library for finite Markov kernels: NumPy tensors with a
domain, a codomain, and optional string labels. Composition, tensor product,
copy, discard, conditioning, and Bayesian inversion are methods on
:class:`fxtensor_salmon.FXTensor`.

This is the English documentation for release |release|.
`日本語 <../ja/index.html>`_ is linked from the bar at the top of every page
and from the sidebar.
